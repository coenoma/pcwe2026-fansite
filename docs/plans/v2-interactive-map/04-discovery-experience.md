## 1. 体験の 4 段階

```
[1. 着想]      → 「行く前から検索しときたい」
[2. 来場直後]   → 「メインゲートに来た。何があるか俯瞰したい」
[3. 巡回中]    → 「ブースの前にいる。ここ何？　次どこ？」
[4. 振り返り]  → 「今日会えた番組を記録したい」
```

各段階で UI が必要な情報量は違う。

| 段階 | 主な情報ニーズ | 推奨 UI |
|---|---|---|
| 1. 着想 | 何が出展、何があるか俯瞰、お気に入りピン | **リスト + フィルタ**（マップは補助） |
| 2. 来場直後 | 全体地図、入口からの位置関係、目当て番組の場所 | **マップ全体** + 検索 |
| 3. 巡回中 | 現在ブース → 隣接ブース、ボトムシート即起動 | **マップズーム** + ボトムシート |
| 4. 振り返り | 今日訪れたブース、買った物、印象 | **「会えた」記録** + シェア |

## 2. 上部固定バー（共通）

```
┌──────────────────────────────────────┐
│ ← 戻る  PCWE2026 マップ  [🗺] [☰]  │  ← 表示モード切替
├──────────────────────────────────────┤
│ 🔍 番組名・ブース・キーワード検索    │
├──────────────────────────────────────┤
│ [両日] [土] [日]                     │  ← 日付チップ
│ [全部] [🍴食] [🎟体験] [🔮珍しい]    │  ← グッズフィルタ
│ [🎁無料配布] [✨新作] [📕読み物]      │
└──────────────────────────────────────┘
```

- **モード切替アイコンは大きめタップ領域**: 当日のリスナーが片手で操作できるように
- **検索バー**: 入力中は他バー（フィルタチップ）を一時的に隠して検索結果に集中
- **フィルタ折りたたみ**: フィルタ未選択時はチップが見える、何か選んだら「✨新作 +2 つ ▾」のように畳まれて再展開できる

## 3. マップビュー詳細

### 3-1. レイアウト

```
┌──────────────────────────┐
│ [上部バー]               │
├──────────────────────────┤
│                          │
│   [SVG 会場マップ]       │
│   ── テント・ピン ──     │
│   ── ロゴ・装飾 ──       │
│                          │
├──────────────────────────┤
│ [📍 お気に入り 3] [⏱ 推奨ルート] │  ← 下部ユーティリティバー
└──────────────────────────┘
```

### 3-2. ピンタップ → ボトムシート

ピンを押すと `BoothBottomSheet` が下から 60vh の高さでせり上がる。背景マップは半透明オーバーレイで残る（マップから完全に離れない）。

```
┌──────────────────────────┐
│  ─                       │  ← drag handle
│ [サムネ]  愛の抵抗       │
│ #ZINE #ペーパー          │
│ 📍 11-B (両日)           │
│ ─────                    │
│ 「Love Letter from 愛..」│
│ 「あすけん生活」         │
│ 「好（ハオ）」           │
│ ＋4 件                   │
│                          │
│ [⭐️ お気に入り] [✅ 会えた]│  ← LocalStorage 保存
│ [📖 番組詳細を見る →]     │  ← 別タブで /booth/pcwe-002
└──────────────────────────┘
```

**設計詳細**:
- **ヘッダー**: サムネ（左）+ 番組名 + ジャンル/グッズタグ + 位置
- **本文**: 物販上位 3 件 + 「+ N 件」省略表示
- **CTA 1（お気に入り）**: ⭐️ アイコントグル。LocalStorage に `pcwe-002` 等を保存
- **CTA 2（会えた）**: ✅ 日付付きで記録。当日「達成感ゲージ」演出に使う
- **CTA 3（詳細を見る）**: 主役 CTA。`target="_blank"` で別タブ
- **drag handle スワイプアップ**: 全画面化（90vh）して物販詳細を全部見れる
- **drag handle スワイプダウン**: 閉じる

### 3-3. テント全体タップ（quad テント）

`shape: 'quad'` のテントを **テントの中心** でタップすると、4 区画分のクイックビューが出る:

```
┌──────────────────────────┐
│ テント 14（土曜）          │
├──┬──┬──┬──────────────┤
│A │B │C │D              │
├──┼──┼──┼──────────────┤
│オバトーク │ピーチウーロン│  ← 横スクロール可能なミニカード
│#体験 #食 │#ZINE         │
└──┴──┴──┴──────────────┘
[←] でテント全体ビュー閉じる
```

- 4 区画を **横並びカード** で表示
- 各カードタップで通常のボトムシート展開
- 「土日の同じテントを比較したい」ニーズには **日付トグル** を このビュー内にも持たせる

### 3-4. ピンの視覚状態

| 状態 | 見た目 |
|---|---|
| 通常 | プライマリ色の塗り（ブランド色） |
| ホバー / フォーカス | 8% 拡大 + ボーダー強調 |
| 選択中（ボトムシート開いてる） | 波紋アニメーション |
| フィルタ非対象 | 30% 半透明 |
| お気に入り済み | ⭐️ アイコンを右上に重ねる |
| 「会えた」済み | ✅ アイコンを右上に重ねる |
| 検索ヒット | 黄色い波紋（注意喚起） |

### 3-5. ズームレベル別表示

- **0.7x（全体）**: テント数字だけ。131 個のラベルが画面に収まる
- **1.0x（デフォルト）**: テント数字 + 主要装飾（ロゴ、メインゲート矢印）
- **2.0x（中ズーム）**: A/B/C/D ラベル + 番組サムネが小さく
- **3.0x+（近ズーム）**: 番組名（短縮）も併記

## 4. リストビュー詳細

### 4-1. レイアウト

マップで「見つけにくい」「俯瞰したい」とき向け。

```
┌──────────────────────────┐
│ [上部バー]               │
├──────────────────────────┤
│ ヒット 12 件 / 全 142 件 │
├──────────────────────────┤
│ ┌────────────────────┐ │
│ │ [サムネ] 愛の抵抗   │ │
│ │ #ZINE #食          │ │
│ │ 📍 11-B (両日)      │ │
│ │ 本茶セットの試飲... │ │  ← merchandiseSpotlight
│ └────────────────────┘ │
│ ┌────────────────────┐ │
│ │ [サムネ] 風呂あがり... │ │
│ │ ...                  │ │
│ └────────────────────┘ │
└──────────────────────────┘
```

### 4-2. 並び順切替

- **デフォルト**: ブース番号順（マップを左上から右下へ走査する自然順）
- **おすすめ順**: `merchandiseSpotlight` がある番組を上、人気カテゴリ持ちを上
- **新着順**: `merchandiseDetails[].sourcePublishedAt` の最新順
- **お気に入り上**: ユーザーがピン留めしたものを最上位

### 4-3. リストカードの情報密度

- 1 カードで **3-4 行** におさめる（モバイル 1 画面で 4-5 件見える設計）
- サムネ 64x64 px
- カテゴリチップは 2-3 個まで
- タップでマップビューに切替 + 該当ピンに自動ズーム + ボトムシート開く

## 5. お気に入り → 推奨ルート（追加提案 α）

### 5-1. UX

ユーザーが ⭐️ を 3 件以上立てると下部に出る:

```
[⏱ 推奨ルート（3 件、約 15 分）→]
```

タップすると:

```
┌──────────────────────────┐
│ あなたの巡回プラン        │
├──────────────────────────┤
│ ① メインゲート → ②        │
│ ② 11-B 愛の抵抗          │
│ ③ 14-B オバトーク         │
│ ④ 25-A ピーチウーロン     │
│ → メインゲート（戻る）   │
│                          │
│ 推定時間: 15-20 分       │
│ （混雑で前後あり）       │
└──────────────────────────┘
```

### 5-2. 計算ロジック（軽量）

- 各テントの中心座標は `booth-positions.json` から取得
- 巡回セールスマン問題（TSP）を **欲張り法（最近傍法）** で解く（3-7 件なら一瞬）
- メインゲートを start/end に固定
- 計算結果を SVG マップ上に **点線パス** で描画

### 5-3. 留意

- 屋内 GPS は使わない。経路は **マップ上での「見える順序」のヒント** にとどめる
- 「最短」と謳わず「巡回プラン」と表現（混雑次第で変わる）

## 8. URL 状態保存（追加提案 η）

### 8-1. 仕様

```
/map?day=sat&cat=food-drink,experience&pin=14-A&q=占い
```

| パラメータ | 意味 |
|---|---|
| `day` | `sat` / `sun` / `both`（デフォルト both） |
| `cat` | グッズカテゴリ（カンマ区切り、複数可） |
| `pin` | 開いているボトムシートのブース位置 |
| `q` | 検索クエリ |
| `view` | `map` / `list`（デフォルト map） |

### 8-2. 効用

- SNS シェア（「ここ気になる」を URL でリンク共有）
- ブラウザの戻るボタンが意味を持つ（タブ切替で迷子にならない）
- ブックマーク可能

### 8-3. 実装

Next.js の `useSearchParams` + `useRouter` でクライアントサイドで管理。SSG なので URL は静的にも有効。

## 9. アクセシビリティ詳細（追加提案 δ）

### 9-1. キーボード操作仕様

| キー | 動作 |
|---|---|
| `Tab` | 次のピンへフォーカス（左上 → 右下の論理順） |
| `Shift+Tab` | 前のピンへ |
| `Enter` / `Space` | フォーカス中のピンのボトムシート開く |
| `Escape` | ボトムシート閉じる |
| `f` | フィルタチップにフォーカス |
| `s` | 検索バーにフォーカス |
| `m` | マップビューに切替 |
| `l` | リストビューに切替 |

ショートカットは画面内 `?` ボタンで一覧表示。

### 9-2. スクリーンリーダー

- マップ全体: `<svg role="application" aria-label="PCWE2026 会場マップ">` 内に `<title>` `<desc>`
- ピン: `<a tabindex="0" role="button" aria-label="ブース 14-B、オバトーク（土曜出展、グッズ: 体験、食）">`
- ボトムシート: `<dialog role="dialog" aria-modal="true" aria-labelledby="..."> + 自動フォーカス`
- リストモードへの誘導: マップビュー上部に「リストでも見れます (l)」ヒント常設

## 10. オフライン耐性（追加提案 ε）

### 10-1. 想定

会場 HOME/WORK VILLAGE は屋内・地下含む可能性、Wi-Fi なし、4G/5G が混雑で詰まる前提。

### 10-2. 対応

- **SSG**: 静的に HTML/CSS/JS をプリビルド（Next.js export モード既存）
- **Service Worker**: マップ JSON、SVG、サムネ画像を **初回アクセス時にすべてキャッシュ**
- **ファイルサイズ予算**:
  - SVG: < 30KB
  - booth-positions.json: < 50KB
  - サムネ全 142 件: < 5MB（lazy load）
  - 合計: 初回 1-2MB を目安、二回目以降はキャッシュ

### 10-3. ユーザー体験

- 初回アクセス時に「オフラインでも使えます」トースト
- オフライン中は「最後の更新: 5/9 9:00」と上部に表示

## 11. 「現在地っぽい」表現（追加提案 ζ）

### 11-1. 不要なこと

屋内 GPS は精度が出ない。実装しない。

### 11-2. やること

「あなたが今いる場所」をマップ上で **手動指定** できる。

```
[📍 私の現在地] ボタン
→ タップ
→ マップが「現在地モード」に
→ どこかのテントを長押し → そこを「現在地ピン」に設定
→ 巡回ルート計算の起点になる
→ お気に入りピンとの距離が表示される（直線距離 or 仮想動線）
```

これでも「私から近い順に並べる」ことができ、屋内 GPS なしで似た体験が作れる。

## 13. 来年以降への布石

`booth-positions.json` のマッピング作業は今年限りでもないので、**毎年使い回せる JSON 構造** にしておく:

```json
{
  "year": 2026,
  "venue": "HOME/WORK VILLAGE",
  ...
}
```

来年版は `year` を変えて `slots` を更新するだけで済む設計。
