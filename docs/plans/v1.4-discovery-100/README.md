# v1.4 — Discovery 100 点化

## ゴール

タグ・検索・ガチャの「60 点の発見体験」を 100 点へ。
受動的な来訪者にも「自分にハマる番組」と最短距離で出会わせる。

## 追加する 3 つの機能

### 1. ぼくのキュレーション 3 セクション

- 手動でキュレーションした 3 つのレーン（横スクロール）をホームに追加
- 例: 「初めての人にすすめたい 5 本」「両日攻めるならこれ」「マニアックに刺さる」
- 各番組カードは既存の `ProgramCard` を流用（細幅版）

**データ:** `data/curations.json`

```jsonc
{
  "curations": [
    {
      "id": "for-first-timers",
      "title": "ポッドキャスト初心者に、まずこの 3 本",
      "subtitle": "1 本聴くと、世界が広がる入口",
      "programIds": ["pcwe-006", "pcwe-072", "..."],
      "themeColor": "#DC725A"
    }
  ]
}
```

### 2. 気分・シーン入口セクション

- 「いまの気分」から番組と出会う入口カード（4–6 個）
- クリックで `/mood/[slug]` に遷移してフィルタ済み一覧
- 既存タグ（朝向き / 寝る前 / じっくり / 笑える など）を裏でフィルタ条件に変換

**データ:** `data/moods.json`

```jsonc
{
  "moods": [
    {
      "slug": "morning",
      "label": "朝、シャキッとしたい",
      "emoji": "☀️",
      "themeColor": "#F5B962",
      "matchTags": ["朝向き", "軽快", "元気が出る"]
    }
  ]
}
```

ページ: `src/app/mood/[slug]/page.tsx` — SSG で `generateStaticParams`。

### 3. 番組診断（5 問クイズ）

- Hero CTA に「3 分で診断」ボタン → モーダルで 5 問
- 各回答は `tagAffinities: { 朝向き: 2, 笑える: 1 }` を持ち、加算採点
- 最終的にスコア上位 3 番組を「あなたに刺さりそう」として表示
- 結果カードは Gacha 同様 `<dialog>` ベース

**ロジック:** `src/lib/program-quiz.ts`

- `QUESTIONS: QuizQuestion[]`（5 問、各問 3–4 選択肢）
- `scorePrograms(programs, answers): ScoredProgram[]`（タグ + ジャンル + vibe で加点）

**UI:**
- `QuizCta.tsx` — Hero ボタン（CTA）
- `QuizModal.tsx` — `<dialog>` で 5 問 → 結果

## 実装順（簡易 → 高難度）

1. キュレーション（データ定義 + Lane 表示のみ）
2. 気分入口（カード + 動的ルート）
3. 番組診断（モーダル + 採点ロジック）

各々を独立コミット。

## 非ゴール

- AI 生成は使わない（API 費用ゼロのまま）
- 5 番組ベースで「成立する」ことを優先（144 番組フル投入で破綻しないことも担保）
- 既存の検索・フィルタ・ガチャ・気になるは触らない（追加のみ）

## 受け入れ基準

- ホームページのスクロール体験が「探す」→「気分から出会う」→「診断で出会う」→「一覧」の 4 段で構成される
- どの入口からも個別番組ページへ最短 2 タップで到達
- ビルドが通り、5 番組サンプルでも見栄えが破綻しない
