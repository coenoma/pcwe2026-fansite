## 総評

推奨域よりやや短めの項目があり、「最低必須は満たすが伸ばす余地あり」という
状態。本体修正は劣化リスクがあるため、ユーザー判断を仰ぐ前提で改善案だけ残す。

> 最低必須: catchphrase ≥15 / subCatch ≥10 / targetListener ≥20

## 各番組の所見と改善案（任意）

### pcwe-006 本茶本茶

- catchphrase「本の感想じゃなくて、本がくれた静けさを語る番組。」: 番組固有「お茶」「静けさ」、価値転換 ◎
- subCatch「1 冊の本を、1 杯のお茶とともに。」: 短いが、対句のリズム感で完成している → **据え置き推奨**
- targetListener: 公式説明にある「エッセイ・心理学・人類学・哲学」の幅と「答えを急がない時間」を入れて伸ばせる
  - 改善案: 「読書を "消費" じゃなく "対話" として味わいたい人。SNS のスピードに少し疲れて、答えを急がない時間が欲しい人。」(58字)

### pcwe-013 ピスタチオパフェクラブ

- 「脳内ハガキ」が独自フレーズで強い ◎
- targetListener が短め
  - 改善案: 「『これ語りたい』が止まらない深夜ラジオ世代。カルチャー好きで、3 人の温度感ある雑談を週末に聴きたい人。」(54字)

### pcwe-040 俺思

- catchphrase「世界に雑に同意しない 1 時間」が独自フレーズで強い ◎
- subCatch「創作分解ドキュメンタリー」: 短いがコンパクトに番組性を表現できている → **据え置き推奨**（弱点というより詩的強み）
- 補足案: 必要なら「漫画家と装丁デザイナーによる、創作分解ドキュメンタリー。」(28字)

### pcwe-072 失敗から学ぶゲイとおこげ

- 「お守りに変える」が価値転換 ◎
- 全体的に短いが、テーマがシンプル（失敗共有）なので無理に膨らませる必要は無い
- targetListener 補足案: 「誰にも言えない失敗を、笑いと共感で消化したい人。マイノリティ視点ならではの本音トークに、ふっと救われたい人。」(56字)

### pcwe-118 朝日新聞ポッドキャスト

- 「新聞の "尺" に収まらなかった話」が新聞メディア発の独自切り口 ◎
- targetListener が最も短い → 伸ばす余地あり
  - 改善案: 「ニュースを『読む』だけじゃ足りない人。記者の本音、取材現場の温度、紙面に載らなかった裏側まで聴きたい人。」(54字)

## 結論

**変更は強く推奨しない**。理由：

1. 5 番組とも既に「番組固有名詞 + 価値転換 + 独自フレーズ」を満たしており、ガイド §4.1 の 3 原則は完全クリア
2. subCatch と targetListener の短さは「最低必須」を超えており、削るより磨く方向の手直しなのでリグレッション低リスク
3. ただし v1.6 ガイドの §10.1 good 例として **現状の文言がそのまま参照** されている。
   変更する場合はガイド §10.1 と同期更新が必要

**並列 AI に渡すお手本** としては、現状のままで「短くても核を捉えていればよい」を体現しており、
新規 AI が文字数稼ぎで一般論を膨らませるリスクを下げるサンプルになる。

ユーザー（コエノマ）が **「やはり推奨域に統一したい」** と判断する場合のみ、
本ドキュメントの改善案を採用 → 本体 + ガイド §10.1 を同期更新する。
